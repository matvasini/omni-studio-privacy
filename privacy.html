Privacy Policy

Last updated: November 2026

1. Overview

Omni Studio Network ("we", "our", or "the studio") provides automated classical concert audiovisual production and YouTube publishing tools. We value and respect your privacy.

2. Data Collection and Usage

Omni Studio Network does not collect, harvest, store, or sell personal information of any kind. We do not use advertising trackers, cookies, or telemetry analytics.

3. Google & YouTube API Services

Omni Studio Network interacts with YouTube API Services under Google OAuth 2.0 authentication strictly to manage and upload classical music content to the studio owner's authorized YouTube channels.

  • Scopes Used: We access the YouTube Data API v3 solely for video file uploads, playlist organization, title/description management, and pinned comment moderation.
  • Storage of Credentials: OAuth 2.0 access and refresh tokens are stored exclusively in encrypted form on the local machine of the operator and are never transmitted to external third-party servers.
  • No Data Sharing: We do not share Google or YouTube user data with any third parties or external services.

4. User Control & Revocation

You can revoke Omni Studio Network's access to your Google/YouTube account at any time via the Google Security Permissions Settings.

5. Contact

If you have any questions about this Privacy Policy, please contact the developer via the official project repository or Google Cloud Console contact point.
